## 先搞清楚：VPS 的“稳定”到底由什么决定

决定晚高峰体验的，是机房到国内三大运营商的回程线路等级。搬瓦工的套餐价格差异，基本上就是线路等级的差异。

- **163 骨干网**：电信默认国际线路，成本最低，晚高峰拥堵、丢包明显。KVM 基础套餐走这条线，便宜但别指望晚上稳。
- **CN2 GT**：电信次高级，比 163 强不少，晚高峰仍会受影响。CN2 特惠方案走这条线。

## FAQ

**流量用超了会扣钱吗？** 超额后实例直接停机，等下个计费周期恢复，不会自动扣费。注意流量按双向计费，上传和下载都算进去，实际可用量比标称数字体感上要打个折。

**支持支付宝吗？** 支持。支付宝、微信、PayPal、银联、信用卡都能用，下单后服务器 1–3 分钟内自动开通，IP 和 root 密码在 KiwiVM 面板里直接看。

**系统装不了 Windows？** 不能。官方支持 CentOS、Debian、Ubuntu、RockyLinux、AlmaLinux，另提供手动 ISO 安装。需要 Windows 远程桌面环境的，这套产品不合适。

**看中的套餐显示缺货怎么办？** 搬瓦工部分套餐限量补货，热门款经常 out of stock。缺货时只能等补货，第三方有实时库存监控页可以盯。

**KVM 和 CN2 套餐能换成 GIA-E 吗？** 不能跨系列升降配迁移，只能在同系列机房间切换。买之前想清楚线路需求，比事后补救省事。
